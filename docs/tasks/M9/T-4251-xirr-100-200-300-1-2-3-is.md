## Goal
XIRR gives Excel's value where no rate makes XNPV zero and the first value is nonzero, as for
`XIRR({-100,200,-300},{1,2,3})`.

## Context
Found by T-3312 (probes/t3312-xirr-xnpv-inner-calls, excel-graph, 2026-11-04):
`XIRR({-100,200,-300},P!G1:G3)` with G1:G3 = 1, 2, 3 is 2.9802322387695314e-09 (0.1/2^25) in Excel and `#NUM!` in the
engine. The flows sum to -200 over two days, so XNPV is about -200 at every rate and has no root, and Excel still
returns the default guess halved 25 times, the value financial.md "XIRR is a bracketing bisection" describes for a
flat XNPV (all-equal dates, A8/A12 there) and for XNPV(0) = 0 (the T-2728 bullet). Here neither holds: the dates
differ and XNPV(0) = -200. Start from `compute_xirr` and `xirr_bracket` (crates/rustsheet-engine/src/functions/
financial/financial_util.rs): find which bracket rule lets Excel bisect here, probe neighbours (other day spans,
other signs, a guess) and check the rule against the T-3268 fitted cells.
