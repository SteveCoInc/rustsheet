## Outcome

register truncated (`half_step_split` in formatter/elapsed.rs, now shared with `date_section_register`): `y = x +
0.5/(86400*scale)`, `floor(frac(y)*86400*scale)`. The elapsed counts keep the value rounded to the shown digit, and
formats without fraction digits are unchanged. `TEXT(1+0.25/86400,"[h]:mm.0")` is "24:00.2".
