# 0342 — Excel-saved oracle downloads are a vendored gated round-trip suite

- **Status:** accepted (2026-11-07, T-4187).
- **Context:**
  - T-4187 needed what Excel for the web writes in a saved PivotChart part (series references, caches, format
    codes) as committed evidence, not a cached download (pivots.md's evidence rule).
  - The download carries the oracle's RustSheetCanary sheet, so it cannot be a fixtures cell case:
    `embed_canary` refuses a second canary. As a round-trip case it is still scored by SPEC-0033.
- **Decision:**
  - Packages Excel saved in an oracle run may be committed byte for byte under `eval/roundtrip/excel-saved/cases/`,
    named after the probe case they are the download of. That probe's `.oracle.json` sidecar records the input
    sha256 they were made from.
  - The suite `roundtrip-excel-saved` is vendored and gated (`gate = true`), like `roundtrip-fixtures`. CI's PR
    gate checks it, and `docs/process/quality-gates.md` names it.
- **Consequences:**
  - This adds a gate and weakens none. Its baseline `eval/baseline/roundtrip-excel-saved.txt` is generated by
    `make eval-baseline` like every other baseline, and may only shrink. T-4950 owns the R0 losses it records
    today: drawings and charts are dropped when a refreshed pivot regenerates the package.
  - A committed download must carry no personal data. Generic SharePoint metadata ("SharePoint App", content
    type ids) is accepted, because the file stays byte for byte Excel's.
